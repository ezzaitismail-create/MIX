📖 MIX Command Reference
PAGE SETUP
change background color = [color]
Changes the page background. Example: change background color = #10131a
change text color = [color]
Changes the default text color. Example: change text color = #ffffff
change title = [text]
Changes the browser tab title.
TEXT
say [text]
Displays normal text. Example: say Welcome to MIX
mix like H easy [text]
Creates a large heading. Example: mix like H easy My MIX App
VARIABLES
create variable [name] = [value]
Creates a MIX variable. Example: create variable score = 100
show variable [name]
Displays a variable's current value on the page. Example: show variable score
change variable [name] = [value]
Updates a variable you already created.
add [number] to [name]
Increases a number variable. Example: add 10 to score
subtract [number] from [name]
Decreases a number variable. Example: subtract 5 from score
SERVER STATUS
turn on server = true
Shows a green "online" server badge.
turn off server = false
Shows a red "offline" server badge.
LAYOUT
add line
Draws a horizontal divider.
add space
Adds vertical spacing between elements.
MEDIA & LINKS
add image = [url]
Inserts an image. Example: add image = https://example.com/cat.png
add link = [url]
Inserts a clickable link.
add subheading [text]
A smaller heading, under a main title.
add quote = [text]
Displays text as a styled quote.
add box = [text]
Displays text inside a highlighted card.
add emoji = [emoji]
Shows one big emoji. Example: add emoji = 🎉
GAME MAKER
add player = [emoji]
Places a controllable sprite in a play area.
add joystick
Adds a drag-to-move joystick for the player above it.
add obstacle = [emoji]
Places an obstacle in the last player's play area. Touching it shakes the screen and costs health, if a health bar exists.
add gravity
Adds a Jump button for the player above it.
add switch = [label]
A tappable on/off toggle.
add menu = item1, item2, item3
A simple tappable menu list.
add score = [value]
A HUD-style score display.
add healthbar = [percent]
A HUD-style health bar. Drops when the player hits an obstacle.
FUN & INTERACTIVE
add secret = [text]
Hides text behind a "tap to reveal" card.
add progress = [percent]
Shows a progress bar. Example: add progress = 70
add rating = [number]
Shows a star rating out of 5.
add badge = [text]
Shows a small pill-shaped label.
add countdown = [seconds]
A live countdown timer.
BUTTONS
add button
Creates a plain button that does nothing on its own.
add button = download
Downloads the preview page as a file.
add button = alert
Pops up an alert message.
add button = back
Goes back a page.
add button = reload
Reloads the preview.
add button = rotate
Rotates the preview page 90°.
add button = confetti
Bursts confetti across the preview. Just for fun.
add button = vibrate
Vibrates the device (on supported phones).
add button = fullscreen
Toggles fullscreen for the preview.
add button = share
Copies this mix as a share code, ready to send to a friend.
add button = print
Opens the print dialog for the preview.
ask [question] = [answer]
Sets up a question and its correct answer.
add button = question
Asks the question above it. Wrong answer shakes the screen.
SOUND
add sound = [name]
Plays a sound. Type an unknown name to see the full library.
Library: ding, buzz, coin, pop, success, fail, click, chime, laser, drum
